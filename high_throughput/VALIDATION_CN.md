# 发布前验证（2026-11-09）

在隔离 venv 中复用本机已有依赖，另外安装随包的 MatterSim 推理 wheel 和原版 Phonopy 2.47.1 wheel。实际导入来自该 venv，Phonopy 不含本机的 is_2d 补丁，线上环境未改。

## 实际小任务

使用两张 RTX 4090、两个 worker、每 worker 两个逻辑 CPU；模型真实计算，不是只检查帮助命令或 import。

| 任务 | 维度 | 弛豫 | 压力 GPa | 秒数 | DOS 积分（应为 6） | 状态 |
|---|---|---|---:|---:|---:|---|
| Si_0GPa | 3d | npt | 0 | 11.61 | 5.99790 | DONE |
| Si_2GPa | 3d | npt | 2 | 10.16 | 5.99824 | DONE |
| Si_no_relax_P1 | 3d | none | 0 | 10.41 | 5.99817 | DONE |
| graphene_nvt | 2d | nvt | 0 | 8.95 | 6.00000 | DONE |
| graphene_slab_npt | 2d | npt | 0 | 10.92 | 6.00000 | DONE |

2 GPa 的 Si 体积由 0 GPa 的 40.872052 Å³ 降至 39.991578 Å³，应力对应压力 1.992959 GPa。二维 NVT 和 slab-NPT 保持真空向量，所有二维 qz=0。ZIP CRC、DOS / PDOS 求和通过。固定晶胞 graphene 保留约 −0.278 THz 的低频负值；这里验证功能，不预设示例应稳定。

## 与现网页核心对照

相同 5M 权重、三维 Si、无弛豫、0.01 Å 位移、2×2×2 超胞和 CPU，新旧入口受力最大差 2.04239e-06 eV/Å，力常数最大差 0.000109034 eV/Å²（相对最大值 8.71217e-06），抽样频率最大差 0.000207619 THz。不是逐位相同的声明。

六方、正方、长方和斜二维路径与现网页函数对照，q 坐标最大差小于 10⁻¹⁴。二维 slab 策略、qz=0 网格及 DOS 频率步长的差别在指南中明确记录。

## 任务控制与恢复

- 五个完成任务再次提交全部 SKIPPED_DONE，受力断点 mtime 不变，CSV 保留数值列。
- 显式续算只恢复模拟缺失的一份受力断点，其他 11 份不改。
- 真实子进程在 2 秒缩短期限下返回 TIMEOUT / 124，worker 已退出；正式上限为 1200 秒。
- 强制终止监督进程后，脱离终端的 worker 也停止，验证父进程死亡保护。
- 128 原子 CIF 预检通过，没有执行该扩展结构的受力计算。

见 [VALIDATION.json](VALIDATION.json)。未重算原论文全体数据集，未执行 DFT、热导率或有限温度自由能计算。
