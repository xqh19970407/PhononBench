# Website checkpoint

`mattersim-v1.0.0-5M.pth` is the checkpoint used by the current PhononBench
website. Its size and SHA-256 are recorded in `manifest.json`.

The model is distributed under the MIT license recorded in the Microsoft
MatterSim Model Card. See `vendor/MatterSim/LICENSE.txt` and `MODEL_CARD.md`.
Git stores this file with Git LFS; the complete distribution ZIP contains its
actual bytes. No private fine-tuned checkpoints or user structures are included.
